GuideMe: show me where to click

A Chrome extension that guides you through any website step by step, in English or Urdu. It points at the right button and tells you what to do, so you learn to do it yourself.

Download GuideMe (ZIP) View on GitHub

Needs Google Chrome 116 or newer on a computer. Setup takes about three minutes.

Set it up

  1. Download and unzip

    Press the green Download GuideMe (ZIP) button above, then unzip the file. You will get a folder called GuideMe-main. Keep it somewhere permanent, because Chrome loads the extension from it.

  2. Open Chrome's extensions page

    Websites cannot open this page for you, so copy its address and paste it into a new Chrome tab.

    chrome://extensions

  3. Turn on Developer mode and load the folder

    Switch on Developer mode (top right), click Load unpacked, and choose the GuideMe-main folder, the one that contains a file named manifest.json.

  4. Add your free API key

    GuideMe uses Google's Gemma 4 through the Gemini API, and every person uses their own free key.

    Get a free API key

    Then right-click the GuideMe icon (pin it first from the puzzle-piece menu), choose Options, paste the key and press Save.

  5. Try it

    Open any website, click the GuideMe icon, type what you want to do (for example "apply for undergraduate admission") and press Start. Click the highlighted item, and GuideMe takes you to the next step. Press Stop to finish.

Questions

Why do I have to use Developer mode?

Chrome only lets websites install extensions from the Chrome Web Store. GuideMe is loaded directly from the folder you downloaded, which is why Chrome asks for Developer mode. Nothing is installed anywhere else.

What is sent to Google?

To choose the next step, GuideMe sends the page title, its address, your goal, and short texts of buttons, links and info on the page from your browser to Google's Gemini API. GuideMe has no server of its own and keeps your API key only in your browser.

It says "Add your API key in Options" or "Cannot run on this page"

Paste your key in Settings (the gear in the side panel) and press Save. Chrome does not allow extensions on chrome:// pages or the Chrome Web Store, so open a normal website instead.
